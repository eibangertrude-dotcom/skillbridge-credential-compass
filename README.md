# Skillbridge Credential Compass

SDGs 4 & 8 FOCUS - PROVING SKILLS WITHOUT PAPER RECORDS (Assess real-world competencies and fund targeted bridging certifications)

Build a simple, modern, responsive web application called Credential Recognition System designed to help an institution receive, review, verify, and manage academic credential recognition applications. 

Include:
- A professional homepage with a brief introduction and navigation menu.
- Applicant registration and login pages (with quick role/demo switching for smooth presentation during evaluation).
- An applicant dashboard where users can submit applications and track their progress.
- An application form containing full name, contact details, institution attended, qualification obtained, course studied, year of completion, country of institution, and document upload for academic certificates and transcripts.
- An administrator dashboard where administrators can view, search, filter, and review applications, examine submitted documents, add comments, and approve, reject, or request additional documents.
- Application statuses: Pending, Under Review, Approved, and Rejected.
- A simple reports section displaying total applications and the number of approved, rejected, and pending applications.
- Clean academic design with navy blue, white, and light grey colours, readable fonts, simple navigation, and a responsive layout that works on both mobile phones and computers.
- Clean, well-organized code that is easy to understand, maintain, and explain during project assessment.
- Sample data for demonstration, ensuring all main buttons, forms, and navigation work properly.
- A lightweight frontend with functional state, avoiding unnecessary complex animations or dependencies. The goal is to create a functional, lightweight student project that is easy to develop and demonstrate.
